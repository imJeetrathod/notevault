export function useAutosave(value, save, delay = 400) {
  const timer = useRef();
  useEffect(() => {
    clearTimeout(timer.current);
    timer.current = setTimeout(() => save(value), delay);
  }, [value]);
}

Install

Running in under a minute.

  1. Download the zip

    NoteVault-1.0.0-windows.zip (268 KB). Extract it anywhere, for example Downloads.

  2. Double-click Install NoteVault.cmd

    No admin rights needed. If Node.js is missing, the installer offers to install it for you, then opens NoteVault.

  3. Start writing

    From now on: Win, type notev, Enter. Or Ctrl+Alt+N. You can delete the zip.

Requirements

  • Windows 10 or 11. Not available for Mac or Linux yet.
  • Microsoft Edge, which comes with Windows. NoteVault opens in its own window.
  • Node.js 22.13 or newer, free. The installer can set it up.

Windows may show a SmartScreen warning because the installer isn't code-signed yet. Choose More info, then Run anyway. The full source is on GitHub if you'd like to read it first.

Privacy

Your notes never leave your PC.

No account, no cloud, no tracking. NoteVault runs a tiny server on your own computer that only your computer can reach.

%LOCALAPPDATA%\NoteVault\notes.db
  • Works offlineNothing to sign into. No internet needed after installing.
  • Daily backupsA copy of your notes is kept every day for the last 14 days.
  • Easy to leaveUninstalling keeps your notes. They're a normal SQLite file you can open anywhere.

Questions

Good to know

Is it really free?

Yes. There's no paid plan, no account and no ads.

Can I bring my existing Notepad tabs?

Yes. Open Settings → Data → Import. NoteVault reads Windows Notepad's unsaved tabs and copies them in, skipping any it already has.

Why does it need Node.js?

NoteVault's engine is a small Node.js program that stores your notes and serves the app to Edge on your own PC. It's the same Node.js developers already use; the installer checks the version and can install it with winget.

Where are my notes, and how do I back them up?

Everything lives in %LOCALAPPDATA%\NoteVault: notes.db for your notes, images for pasted pictures, and backups for the daily copies. Copy that folder to back it all up.

Does it work on Mac or Linux?

Not yet. NoteVault is built around Windows: the Start menu, Ctrl+Alt+N, Notepad import and the Windows 11 glass look.

How do I uninstall it?

Run Uninstall NoteVault.cmd from the folder you extracted. The app and shortcuts are removed and your notes are kept, in case you change your mind.
